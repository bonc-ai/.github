## CogSeed — 个人 AI 智能伴侣

本地优先的 AI 协作桌面工作台，将经用户确认的偏好、项目约束和有效经验沉淀为可追溯的认知资产，在后续相关任务中复用，并支持在不同受支持的 Agent 之间接续任务。

## 参与社区

欢迎通过以下方式参与：

- **体验与反馈**：在对应项目的 Issues 中提交问题、复现步骤或功能建议。
- **代码与文档贡献**：先阅读对应项目的贡献指南，再提交 Pull Request。
- **交流与讨论**：在已开放 Discussions 的项目中分享使用经验和想法。

参与社区请遵守[贡献者行为准则](https://github.com/bonc-ai/.github/blob/main/CODE_OF_CONDUCT.md)。

## 安全与许可证

安全漏洞请通过私密渠道报告，勿在公开 Issue 或 Pull Request 中披露。请优先遵循对应项目的安全策略；组织级报告方式见[安全策略](https://github.com/bonc-ai/.github/blob/main/SECURITY.md)。

各项目分别适用其仓库中的许可证。Fork 项目的上游来源、版权及许可证信息请参阅对应仓库。
